## Design Context

**Target audience**: Developers and operators who drive Pre-IPO perp markets through the `offchain-platform-backend` REST API (emulator, preprod, or mainnet-style flows).

**Use cases**: Lock a market, submit oracle updates, swaps, mint/redeem; copy transaction hashes and open explorer links; inspect parsed datum state from a spend transaction.

**Brand personality / tone**: Editorial financial terminal—precise, calm, confident. Warm paper-like surfaces and deep ink text; one restrained accent (teal/copper), no crypto-neon or purple gradients.

**Constraints**: Must work with Vite dev server; API base URL configurable via `VITE_API_BASE`; keyboard-accessible forms; readable at 1280px+.
